# Carpet Studio website

The public landing page is hosted at https://carpet-studio-kevish.sacredsun4096.chatgpt.site. This folder contains the static HTML, CSS, JavaScript, and design assets. The browser demo lets visitors move and lift a sample carpet, gather sample icons, and switch designs. It never touches a visitor's real desktop.

The hosted Sites project also contains `downloads/Carpet-Studio-0.2.0-preview.dmg`. The DMG is generated by the Mac app's `build.sh` and `package-dmg.sh` scripts and is not committed to this GitHub repository. To preview this website locally with a working download link, copy the generated DMG into `website/downloads/`, then serve this folder as the web root.

This is a development preview. A broadly installable Mac release still requires a Developer ID Application certificate and notarization.
